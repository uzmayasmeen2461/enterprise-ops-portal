## Four Resume Bullet Points

Use these under a "Projects" or "Skills" section. Be honest that it's a POC, not production work.

---

**1. Architecture & State Management**
> Built a feature-based Angular 22 application using standalone components, Angular Signals, and `computed()` for reactive UI state — replacing traditional `BehaviorSubject` / `async` pipe patterns with a simpler, subscription-free model.

**2. Forms, Routing & Security**
> Implemented authentication with Reactive Forms (FormBuilder, Validators, typed controls), functional route guards (CanActivateFn), and a functional HTTP interceptor that injects mock JWT tokens into every outgoing request.

**3. Advanced Angular Patterns**
> Authored custom structural and attribute directives (role-based DOM gating, hover highlight), a pure custom pipe (status formatting), lazy-loaded routes with component input binding, and an InjectionToken-based AI service abstraction designed for a real LLM backend swap with zero component changes.

**4. Testing**
> Wrote a Vitest unit test suite covering service logic (signals, localStorage, navigation), a pure pipe, a functional route guard (TestBed.runInInjectionContext), and a Reactive Forms component — including form validation states, signal assertions, and mock service injection.

## Honest Positioning Note

When discussing this project in interviews or on your CV, position it accurately:

✅ *"I built this as a structured POC to develop hands-on Angular experience"*
✅ *"It demonstrates the patterns I'd apply in a production Angular codebase"*
✅ *"I can walk through the architecture, explain every design decision, and discuss trade-offs"*

❌ *"I used this in production at [company]"* — don't say this

Interviewers respect engineers who built serious projects to learn a framework.
What they test is whether you actually understand the code — and you do.
